# Launchpad Clone

一个仿 LaunchOS / 原生启动台的 macOS 应用启动器,原生 Swift + SwiftUI 编写。

> 项目理念(与 LaunchOS 一致):不堆功能,专注打磨那些"消失时会立刻被察觉"的细节体验。

- [x] 扫描系统与用户应用目录(`/Applications`、`/System/Applications`、`~/Applications` 等)
- [x] 全屏网格展示应用图标(自适应列数)
- [x] 实时搜索过滤(输入即搜)
- [x] 点击图标启动应用
- [x] 毛玻璃(ultraThinMaterial)背景
- [x] **全屏无边框覆盖层**(盖在普通窗口与 Dock 之上,不占 Dock 图标)
- [x] **`Esc` 关闭**;搜索非空时 `Esc` 先清空搜索
- [x] **点击空白区域关闭**
- [x] **显示后自动聚焦搜索框**,无需点击直接输入
- [x] **菜单栏图标**:左键唤起/关闭,右键菜单(显示/隐藏、退出)

- [x] 模型层支持**别名**(搜索按显示名/默认名双路匹配)与**隐藏**(界面操作后续做)

- [x] **跟手拖拽翻页**:拖拽位移实时更新,按预测终点(含甩动速度)决定翻页
- [x] **滚轮/触控板翻页**:带冷却防抖,一次滚动只翻一页(平滑滚轮/惯性兼容)
- [x] **`⌘←` / `⌘→` 键盘翻页**(原生同款快捷键)
- [x] **页码圆点指示器**,可点击跳页
- [x] **记住上次页码**:隐藏再唤起停留在原页(原生默认行为)
- [x] **搜索回车直接打开第一个结果**
- [x] **多路匹配搜索引擎**:前缀 / 词首 / 单词首字母(`vsc`、`4kvd`)/ 驼峰缩写 / 包含

- [x] **查询空白归一化**与**无结果反馈界面**;启动时预热 ICU 转换器,首次打字不掉帧

## 构建与运行

```bash
./build.sh
./launchpad
```

> 说明:本机 SwiftPM 清单库损坏,`build.sh` 直接用 `swiftc` 编译。
> 装完整版 Xcode 后可改用 `swift build`,或用 Xcode 打开 `Package.swift`。

## 项目结构

```
Sources/LaunchpadClone/
├── main.swift         # 应用入口:覆盖层窗口 + 菜单栏图标 + 全局快捷键 + Esc
├── AppScanner.swift   # 扫描应用来源目录
├── LayoutStore.swift  # 布局持久化:应用/组/来源模型 + 对账 + 落盘
├── SearchEngine.swift # 多路匹配搜索:前缀/缩写/拼音/多音字/匹配度排序
├── KeyboardNav.swift  # 键盘导航纯逻辑:分页/扁平两种网格的方向移动
└── ContentView.swift  # 主界面:搜索框 + 分页网格 + 页码圆点 + 高亮
```
